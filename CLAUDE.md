# Greymere iOS — Claude Code entry point

The native iPhone and iPad app for Greymere (SwiftUI, iOS 26 minimum). A client
of the Greymere server, which lives in `~/Code/greymere` (GitHub
`akguile67/greymere`). This repo holds the app only; server work is done there.

- **Own version line.** The app is iOS X.Y.Z; the board carries the server
  version. Compatibility is a minimum-server-version check against
  `GET /api/instance`.
- **First release: iOS 0.1.0**, a read-only Home screen. The scope is ADR 0.50.0:
  `~/Code/greymere/docs/adrs/adr-0.50.0-ios-0-1-0-mobile-foundation-home-landing-screen.md`.
- **iOS 0.2.0** adds the read-only seed screen (ADR 0.51.0, server release 0.51.0, no server change; minimum server
  version stays 0.50.0). It reads `/api/vault/ideas/:id` and `/api/vault/ideas/:id/research`; the app still writes nothing.
- **iOS 0.7.0** makes a beat's generated draft editable before Accept (server 0.57.0, Bug Hotel #317; minimum server version 0.57.0).
- **iOS 0.4.0** adds dictation (ADR 0.53.0, server release 0.53.0; minimum server version 0.53.0). A third target,
  **GreymereDev** (`com.greymere.ios.dev`), points at a laptop dev server (its address is in `project.yml`).
- **iOS 0.8.0** adds the Planning panel (the Kanban with the current step's dates and standing against the baseline; hold-and-drop on an iPad, a Move to menu on an iPhone) and the Home task cards (tick with hours, swipe, reorder, add by typing or dictation). Both stay live with the desktop over `/api/events`. ADR 0.58.0; server 0.58.0 and minimum server version 0.58.0. Wireframes: `docs/wireframes/planning-wireframes.html`. The dev server is the one the Godric Client (Dev) app starts, on port 3001; never run a second server on the same database beside it (they cannot share events).
- **iOS 0.8.1** adds the studio offers on Home as cards with Add to today and Pin first, and Back to offers on a task that came from the studio (the desktop's `/api/home/studio/*` routes; no server change, minimum server version stays 0.58.0).
- **iOS 0.9.0** adds the Codex panel (ADR 0.59.0, platform card 0.59.0; iOS 0.8.0 is skipped on purpose; minimum server version 0.59.0).
  Browse, search, filter by Series and Book series, edit through review and Apply, new and delete, images (Photos upload,
  Godric-made, thumbnails), Standardise, Find missing, Godric with the open entry as context, Ask the Codex. Exit
  checklist: `docs/codex-exit-checklist.md`; release notes: `docs/release-0.9.0.md`. Server work still owed (aliases and
  parent ids in the list, a stale-write guard, a `codex.changed` event) is in the notes folder.
- **iOS 0.10.0** adds the Structure panel (ADR 0.60.0, server 0.60.0; minimum server version 0.60.0): the acts as cards in a
  grid as in Creation, the six-field briefing on a card (summary headline and five sections), add, rename, delete, hold-and-drag
  reorder within an act, Godric's one Structure thread, live refresh and a stale-write sheet. Draft opens Creation, which offers a
  way back to Structure. Exit checklist: `docs/structure-exit-checklist.md`; release notes: `docs/release-0.10.0.md`.
- **iOS 0.11.0** brings the app to server 0.60.1 (minimum server version 0.60.1): the drafting progress line and tick on Home's Today card,
  the codex-gap sheet (Link, Create, Not required) from the warning triangle in Structure and Creation, Godric's codex draft card and
  `beat_opened` in Creation's chapter chat, and a warning before leaving the brief editor with unsaved edits. Handoff:
  `~/Code/greymere/docs/ios-handoff-0.60.1.md`; exit checklist: `docs/parity-0.60.1-exit-checklist.md`; release notes: `docs/release-0.11.0.md`.
- **Builds happen on the MacBook Pro only** (Xcode, Team ID D25P46655T). Two
  bundle IDs, prod and pre-prod, distributed through TestFlight. Connection is
  over Tailscale.
- **One project per session.** Server changes (the Home aggregate endpoint, the
  version fields) belong in the Greymere repo and its release branch.

## The project

`project.yml` is the source; `Greymere.xcodeproj` is generated by XcodeGen
(`brew install xcodegen`, then `xcodegen generate`) and committed so Xcode opens
it directly. Change settings in `project.yml`, never in Xcode's build settings.

- Two app targets over the same `Greymere/` sources: **Greymere** (prod,
  `com.greymere.ios`, default server `http://100.75.100.51:3000`) and
  **GreymerePreProd** (`com.greymere.ios.preprod`, `…:3100`). The default server
  is the `GreymereDefaultServerURL` Info key; the Connect screen will let it be
  changed.
- Plain HTTP is allowed for that one Tailscale address only (an ATS exception
  per target); the link itself is Tailscale's encrypted tunnel.
- Build check: `xcodebuild -project Greymere.xcodeproj -scheme Greymere
  -destination 'platform=iOS Simulator,name=iPad mini (A17 Pro)' build`.
- Test devices: iPhone 14 Pro and iPad mini 6th generation (real, installed with `xcrun devicectl`), and the
  simulators iPad mini (A17 Pro) and iPhone 14 Pro. The iPad Pro is no longer a target (ADR 0.58.0).
