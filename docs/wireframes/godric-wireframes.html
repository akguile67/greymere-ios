Greymere iOS 0.3.0 — Godric chat wireframes

Drawn against the desktop Godric panel as captured on 29 October 2026 (see godric-chat-exit-checklist.md). Boxes are placeholders, not final styling. As in 0.1.0, one set of screens adapts by size: a full screen on iPhone, a side panel beside Home on iPad. No token streaming and no cost line: the desktop has neither, so the reply appears whole after "Thinking…" (checklist findings 1 and 2).

1 · Where chat lives

A Godric button on Home's top bar (and on Book Details, which opens the same Home thread with that book in focus). The desktop's Godric panel is always at the side; on iPhone it is a full screen you go into and come back from. On iPad it docks to the right of Home, so you can read the shelf while you talk.

3 · Chat on iPad (regular width)

Home keeps the left of the screen; Godric docks on the right, like the desktop. The Godric button toggles it. History opens as a list in the panel. Mini and Pro use the same layout; the divider follows the Home split already built. In portrait on the mini the panel may overlay Home instead of docking.

4 · From Book Details

A Godric button on Book Details opens the same Home thread with that book in focus (bookId sent, and a book-switch note added if it changes). To confirm at the wireframe: the desktop has no Home-with-a-book panel, so this is the closest match for "per-panel context" with the panels the app has. If you would rather keep chat on Home only for 0.3.0, this entry point is dropped.
