Greymere iOS 0.1.0 — Home wireframes

Drawn against the desktop Home as captured on 28 October 2026 (see home-exit-checklist.md). Boxes are placeholders, not final styling. One set of screens: it adapts by screen size (compact on iPhone, regular on iPad), with no separate iPad code.

Three states of the first screen. The server address is remembered after the first time; the app goes straight on to Home when the server is reachable and new enough.
